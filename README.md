# Simple Machine Learning Algorithms

A beginner-friendly collection of Machine Learning algorithms implemented in Python using NumPy and Scikit-learn.

This repository is built as a learning project to understand and implement common Machine Learning algorithms through simple, practical examples.

## Algorithms

### 1. Linear Regression

A supervised learning algorithm used to predict a continuous numerical value based on input data.

**File:** `linear_regression.py`

**Example:** Predicting the output for a given input.

---

### 2. K-Nearest Neighbors (KNN)

A supervised classification algorithm that predicts the class of a new data point based on the classes of its nearest neighbors.

**File:** `knn.py`

**Example:** Classifying a new data point into Class A or Class B.

---

### 3. Decision Tree

A supervised learning algorithm that makes predictions by splitting data into branches based on feature values.

**File:** `decision_tree.py`

**Example:** Predicting whether a student will Pass or Fail based on study hours and practice tests.

---

### 4. Logistic Regression

A supervised classification algorithm used to predict categorical outcomes.

**File:** `logistic_regression.py`

**Example:** Predicting whether a student will Pass or Fail.

---

### 5. Naive Bayes

A probabilistic supervised learning algorithm based on Bayes' theorem. It assumes that features are conditionally independent.

**File:** `naive_bayes.py`

**Example:** Predicting whether a student will Pass or Fail.

---

### 6. K-Means Clustering

An unsupervised learning algorithm that groups similar data points into clusters.

**File:** `kmeans.py`

**Example:** Grouping customers based on spending and purchasing behavior.

---

### 7. Random Forest

An ensemble learning algorithm that combines multiple decision trees to make predictions.

**File:** `random_forest.py`

**Example:** Predicting whether a student will Pass or Fail.

---

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/frostlily2k4/simple-ml-algorithms.git
```

### 2. Open the project

```bash
cd simple-ml-algorithms
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run an algorithm

For example:

```bash
python linear_regression.py
```

Or:

```bash
python knn.py
```

```bash
python decision_tree.py
```

```bash
python logistic_regression.py
```

```bash
python naive_bayes.py
```

```bash
python kmeans.py
```

```bash
python random_forest.py
```
